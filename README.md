# Evoke — built site

This repository holds **only the compiled output** of the Evoke project
page, so GitHub Pages has something public to serve. It is generated,
not authored: every file is produced by `next build` and replaced on
each deploy.

- **Live site:** https://evoke-world.github.io/Evoke/
- **Source:** `Evoke-World/evoke-src` (private)

Nothing here is source code — it is the same minified JS, CSS, HTML and
media a browser already downloads when it loads the page. Do not commit
here by hand; the next deploy discards it.
